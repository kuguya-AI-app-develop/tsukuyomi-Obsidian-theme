# Tsukuyomi 1.0.5 — Mermaid readability

Wide Mermaid diagrams can scroll within the note instead of overflowing its reading area. Flowcharts, sequence diagrams, and state diagrams use Tsukuyomi's dark and light colors. Class, ER, and other diagram types retain their native colors. Mermaid still controls node positions, routing, and inline sizing such as `useMaxWidth`.

- Preserve tested explicit node and edge colors, including readable labels on custom pale backgrounds.
- Add the per-note `cssclasses: [tk-mermaid-original]` option for diagrams with a custom Mermaid theme. It restores native diagram colors while retaining the scroll container.
- Include 12 independent example diagrams in the lab vault. No runtime JavaScript or plugin is required.

## Validation

24 project tests and strict Stylelint passed. A desktop-browser matrix passed 170 cases using the installed Obsidian 1.13.7 CSS and Mermaid 11.13.0, with simulated reading/live-preview DOM, dark/light modes, 393px/700px widths, and baseline/opt-out comparisons. Native macOS Obsidian reading view and an eight-page PDF export were also checked.

These checks do not establish iOS WebView or touch-gesture support, all diagram/custom-shape compatibility, or native light-mode/live-preview acceptance. Very wide diagrams shrink for printing; large internal gaps still require changes to the diagram's layout. See the [validation record](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.5/docs/VALIDATION.md) for scope and limitations. Official review status is recorded separately in [publishing status](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/PUBLISHING.md).

## Install or roll back

Requires Obsidian **1.13.7 or later**. Extract `Tsukuyomi-1.0.5.zip` into your vault's `.obsidian/themes/` folder and select Tsukuyomi in Settings → Appearance. Alternatively, replace the existing theme's `manifest.json` and `theme.css` with the individual attachments. Notes are not modified.

To restore the prior theme behavior, install the two files from release 1.0.4 or select Obsidian's default theme. The [license and artwork scope](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.5/NOTICE.md) is unchanged.
