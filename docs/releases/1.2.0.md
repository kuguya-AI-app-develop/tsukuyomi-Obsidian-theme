# Tsukuyomi 1.2.0 — Navigation and note motion

This update adds more visible, slower interaction feedback while retaining Tsukuyomi's palette, typography, artwork, and empty-view scenery.

- Selected file and tab labels/icons, plus expanded folder names, gain a `520ms` jelly bounce. Selected module icons in both sidebars use a stronger `600ms` bounce. Clickable parent rows remain fixed.
- Newly created or redisplayed note views enter over `460ms`, moving upward `14px` as opacity rises from `0.3` to `1`. This applies to ordinary hidden-tab restoration and Reading/editing view switches.
- **Static scene**, system reduced-motion preferences, and printing disable these animations. There are no new settings, runtime JavaScript, dependencies, or required plugins.

Replacing a file in the same tab may reuse its view, so note entrance is not reliable for that operation. Focusing an already visible split or stacked pane does not replay it; typing and scrolling do not trigger it. There is no outgoing crossfade because the CSS theme does not control view removal.

## Validation and limits

29 project tests and strict Stylelint passed. Eight desktop-browser cases passed 620 assertions, covering motion, static mode, and sidebar geometry using Obsidian's native CSS. Reduced-motion guards were covered by policy tests; the system setting was not changed during browser testing. Native macOS Obsidian **1.13.7** checks covered switching the left sidebar to Search and the right sidebar to Backlinks.

The browser checks use simulated DOM and do not replace iPhone testing. iPhone motion, Chinese IME composition, and caret behavior during the instant of native view entrance remain untested. See [validation](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.2.0/docs/VALIDATION.md) for scope and evidence. Official scanning and directory availability are recorded separately in [publishing status](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/PUBLISHING.md).

## Installation

Requires Obsidian **1.13.7 or later**. Extract `Tsukuyomi-1.2.0.zip` into your vault's `.obsidian/themes/` folder, or replace the theme's `manifest.json` and `theme.css` with the individual attachments. Select Tsukuyomi in Settings → Appearance. To roll back, install both files from [1.1.0](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/releases/tag/1.1.0); notes remain unchanged.
