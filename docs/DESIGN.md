# 设计说明

Tsukuyomi v0.7.0 结合用户选择的月读城市与八千代舞台两种场景。街景招牌、朱红与海青框线，以及空白页的城市和舞台构图共同表达原作空间；阅读与编辑区域始终使用不透明的纯色背景。保留 Obsidian 与用户配置的字体、字号，正文默认宽度 `40rem`、行高 `1.75`。深浅模式跟随 Obsidian 的外观选择。

## 从场景到界面

以下将资料中的场景事实与本项目的设计取舍分开。来源及其用途见 [SOURCES.md](SOURCES.md)。

| 资料依据 | 本项目的转化 | 阅读边界 |
| --- | --- | --- |
| 制作访谈区分京都式街景、较低饱和度的游戏空间和激光演唱舞台 | 结合城市与舞台的识别元素，用于界面框线与空白页场景 | 阅读区域不承载演出效果 |
| 官网故事图中的朱红叠层建筑、暖窗、青粉招牌与发光骨架鱼 | 原创城市 SVG 使用几何楼阁、数字招牌和骨架鱼线条 | 城市仅放在空白页下方，不铺在文件名或正文下 |
| 制作图中的鸟居、城台、圆形水镜与虹色拱桥 | 原创舞台 SVG 使用鸟居、圆镜、三色拱桥、水面及灯笼 | 空间足够时舞台居中、操作独占下一行，城市位于底部 |
| 场景中的朱红建筑与青色虚拟光线 | 当前标签使用朱红与海青框线，工具区和标题栏边缘恢复本项目 v0.2 的青色短斜线与淡几何纹理 | 纹理仅位于导航标签区和边条，不进入文件列表或正文 |
| 用户提供的 irop.one 参考站中的海军蓝、奶油色标签、青绿与珊瑚偏移边框，以及云环形态 | 侧栏灯牌和工具区采用原创 CSS 框线，选中文件使用不透明奶油色底 | 文件名文字背后不放云纹、环形图案或场景素材 |
| 官网 DOGE 与 FUSHI 的角色图 | 以矢量二创分别放在空白页上方左侧和右侧，DOGE 按参考细化耳形与面部 | 独立伙伴图层留在空白区域，与鱼使用相同的静态回退条件 |
| 用户提供的粉色伙伴截图 | 保留粉色身体、耳状鳍、深紫眼睛和触腕，去除头像圆框，放在上方中央 | 仅作为外形参考，未确认官方名称；不进入正文或原生操作区 |
| 用户提供的彩叶狐狸装扮参考 | 仅重绘头部，放在上方中央偏左的留白 | 不添加身体，不另取官方吉祥物名称，与其他伙伴共用回退条件 |

这些是为笔记工具重新组织的视觉表达。色值不是官方标准色，也不是从电影画面精确取样的结果。

## 色彩与排版

深色「月读夜景」的正文背景为 `#1c2330`，侧栏为 `#101d32`，浮层为 `#253044`，正文为偏暖的 `#e9e3d5`，次级文字为 `#b6b4ba`。浅色「月白」保留纸白背景 `#f7f5f0`、侧栏 `#ecefea` 与深色正文 `#273442`。

| 色彩 | 深色 | 浅色 | 主要用途 |
| --- | --- | --- | --- |
| 海青 | `#82cabb` | `#0f706a` | 主强调、链接、焦点与选中状态 |
| 朱红 | `#e6a098` | `#ac3c50` | 错误、危险与未解析链接 |
| 月金 | `#dfc38a` | `#84621b` | 警告、代码强调与灯火 |
| 月紫 | `#bcb0df` | `#7053a2` | 外部链接、引用与辅助强调 |

标题通过字号、字重与间距建立层级，不使用发光、底纹和大型标题卡片。文件列表保持纯色底，与上方灯牌分开；选中文件采用奶油色底与深色文字，青绿标记和珊瑚色偏移边框强化状态。键盘焦点保持可辨识。控件、内容块和浮层使用 `6 / 10 / 14px` 圆角，键盘 `:focus-visible` 使用 `2px` 轮廓。

原生主题色设置可覆盖链接、按钮和焦点的交互色，装饰与提示块保留主题配色。自动对比度检查针对默认色板；用户自定义颜色不在此保证范围。Canvas 保留红、橙、黄、绿、青蓝、紫六个颜色槽的区分。原生强调色文字适配的核对记录见 [native-color-reference.txt](native-color-reference.txt)。

`40rem` 是本项目的默认阅读宽度，可通过 Style Settings 调整，不等于任何字号下都恰好容纳 40 个汉字。W3C 的 CJK 行长和文字间距资料用于指导可读性取舍，不构成整个主题已通过 WCAG 的声明。

## 装饰与动效

场景由本项目设计的城市、鸟居、鱼和光镜 SVG，以及 DOGE、FUSHI、粉色伙伴和彩叶狐狸装扮头部的矢量二创构成，构建时内嵌到 CSS。`tsukuyomi-city.svg` 保存楼阁、暖窗、数字招牌与水面，`tsukuyomi-gate.svg` 保存鸟居、灯笼、水面与吊线；建筑均保持静止。鱼有静态的 `tsukuyomi-fish.svg` 与动态的 `tsukuyomi-fish-swimming.svg` 两个版本，`tsukuyomi-mirror.svg` 保存圆镜与彩色轨道。灯牌与列表下方的独立装饰区另使用本项目的 `assets/stage-clouds.svg` 云纹。四位伙伴共同使用静态的 `tsukuyomi-mascots.svg` 和动态的 `tsukuyomi-mascots-living.svg`。动态鱼与伙伴 SVG 使用声明式动画；所有资产均无脚本或远程引用。DOGE 和 FUSHI 依据官方角色图重绘，粉色伙伴与狐狸头依据用户图片重绘；粉色伙伴名称未确认。矢量格式不构成原创角色或自动授权声明。

侧栏在文件列表上方单独显示最小高度 `112px` 的「月読 TSUKUYOMI」灯牌，搭配海军蓝、奶油色与青绿、珊瑚框线；云环细节位于灯牌及文件列表下方的独立装饰区。空间足够时，空白页通过三行网格将鸟居与光镜放在中央一行，原生操作独占下一行，水波跟随操作区排列；城市固定在底部约三分之一区域，鱼沿下方两侧游动。四位伙伴使用独立的 `1200 × 800` 画布，分散在上方留白：DOGE 在左、FUSHI 在右、粉色伙伴在中央，狐狸头在中央偏左。操作区保持自身内容高度，避免与舞台叠放。装饰不接收指针事件。笔记、编辑器和文件名文字背后没有场景图案；旧 `tk-home` 类不触发专门的首页样式。

`tk-minimal` 关闭街景招牌、装饰框线与空白页场景。`tk-decoration-opacity` 只控制空白页场景透明度，默认 `0.70`，范围 `0–1`、步长 `0.05`。空白页窗格或窗口的宽度不超过 `600px` 或高度不超过 `560px` 时，隐藏城市、鱼、伙伴、鸟居、光镜和水波六个图层，并恢复原生居中的操作区；打印同样隐藏全部六层场景。窗口宽度不超过 `600px` 时也隐藏侧栏招牌；侧栏宽度不超过 `240px` 时，招牌仅保留居中文字。

动效默认启用，无需插件。两条鱼各保留完整的骨架路径，SVG `<animate>` 用匹配的路径命令连续变形：鱼身弯曲逐渐传到尾部，尾关节与鳍尖随之摆动，头部和眼点相对固定。身体周期分别为 `1.2s` 与 `1.4s`；嵌套的 `<animateTransform>` 与透明度动画按 `18s`、`22s` 时间轴呈现单向游过、淡出和反向鱼淡入；可见期间朝向固定，朝向准备仅发生在完全透明的时段。两条鱼分别留在城市两侧。DOGE 尾部以 `4s` 周期轻摆，FUSHI 以 `5s` 周期轻微浮动，鳃部以 `6s` 周期摆动；粉色伙伴以 `6s` 周期上下浮动 `2px`（SVG 坐标）；狐狸头以 `7s` 周期在 `±1.5°` 间轻摆。光镜使用 `5s` CSS 透明度周期，水波使用 `4s` CSS 缩放与透明度周期；建筑和正文始终静止。

伙伴图层位于 `.workspace-leaf-content[data-type="empty"]::before`，鱼图层位于其 `.view-content::before`，静态版本分别作为 CSS 默认资源。两处动态资源选用规则使用相同条件：空白页为活动窗格、窗口和窗格均至少 `601px × 561px`、系统未请求减少动态效果，并且没有启用简洁或静态模式。非活动窗格、`tk-disable-motion` 或系统减少动态效果使用静态鱼和伙伴；窄小窗格、简洁模式与打印隐藏场景。该回退直接替换图像，不依靠 CSS 暂停 SVG 内部时间轴。主题不因用户切换到其他应用而主动暂停。`tk-disable-motion` 同时关闭默认 `140ms` 界面过渡。

游鱼与角色分别由 `node scripts/generate-fish.mjs` 和 `node scripts/generate-mascots.mjs` 确定性生成；后者调用 `scripts/render-mendako.mjs` 与 `scripts/render-fox.mjs` 的纯渲染函数加入粉色伙伴和狐狸头，无需额外生成命令。模块名只是内部名称，不作为官方角色身份依据。生成器导出纯渲染函数供构建核对资产是否过期；JavaScript 只用于开发，不进入主题运行时。CSS 分发预算为 `80KiB`，每个解码后的 SVG 不超过 `10KiB`，同时保留鱼与伙伴的动静资源。不使用滤镜或全窗模糊。

## 兼容边界

主题优先覆盖 Obsidian 公共 CSS 变量，再为工作区和常用原生视图补充少量选择器。窄屏规则用于基础布局收敛，不据此宣称已完成移动端实机验证。打印规则移除装饰并恢复白底深色文字。

Style Settings 只是可选控制界面；没有该插件时，主题使用内置默认值正常工作。验证状态、桌面版本与未测项目统一记录在 [VALIDATION.md](VALIDATION.md)。
