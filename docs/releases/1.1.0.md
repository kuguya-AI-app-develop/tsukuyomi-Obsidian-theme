# Tsukuyomi 1.1.0 — Interaction details

This update improves everyday navigation and table use while keeping Tsukuyomi's palette, typography, sidebar signs, artwork, and scene animation unchanged. It includes the Mermaid improvements from 1.0.5.

- Menu titles inherit native warning, disabled, and label colors. Ordinary selected menu and command items gain a subtle turquoise inset outline; disabled items do not receive the theme's hover highlight.
- Compact density applies only on desktop. Phones and tablets retain Obsidian's native navigation spacing.
- Wide Reading-view tables scroll within their own wrapper, including narrow desktop panes. Live Preview retains its native table layout, scrolling widget, and editing controls.
- Add `cssclasses: [tk-table-guide]` to a note for optional row hover/focus guidance and tabular-width digits. Merge with existing classes. It is off by default, requires no plugin, and introduces no new Style Settings option.

The interaction ideas were informed by upstream Minimal, Things, and AnuPpuccin documentation and implemented independently using Tsukuyomi's existing design tokens. See [reference notes](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.1.0/docs/UX-REFERENCES.md).

## Validation and limits

24 project tests and strict Stylelint passed. Native macOS Obsidian 1.13.7 checks covered command-palette keyboard selection, scrolling to a wide table's final column, editing and restoring a Live Preview cell, and a two-page Letter landscape PDF. The CSS is 89,071 bytes, below the unchanged 88 KiB budget. See [validation](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.1.0/docs/VALIDATION.md) for the final browser matrix and pointer checks.

Desktop simulations do not replace iOS/Android touch-device testing. OS-native menus are drawn by the operating system and are not recolored by the theme. Printing restores native table layout; arbitrary wide tables are not guaranteed to fit every paper size or orientation. Official scanning and client-directory availability are recorded separately in [publishing status](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/PUBLISHING.md).

## Installation

Requires Obsidian **1.13.7 or later**. Extract `Tsukuyomi-1.1.0.zip` into your vault's `.obsidian/themes/` folder, or replace the theme's `manifest.json` and `theme.css` with the individual attachments. Select Tsukuyomi in Settings → Appearance. To roll back, install the two files from 1.0.5; notes remain unchanged.
