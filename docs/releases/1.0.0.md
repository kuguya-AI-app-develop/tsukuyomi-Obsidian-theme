# Tsukuyomi 1.0.0

首个正式版本。保留已确认的月读视觉：深浅双模式、安静的正文区域、侧栏灯牌与青色斜纹、居中空白页舞台、游动骨架鱼和四位矢量伙伴。电影场景扩展研究暂缓，不纳入本版。

## 安装

需要 Obsidian 1.13.7 或更高版本。下载 `Tsukuyomi-1.0.0.zip`，将其中的 `Tsukuyomi` 文件夹放入笔记库的 `.obsidian/themes/`，然后在「设置 → 外观」选择 Tsukuyomi。也可以将单独的 `manifest.json` 与 `theme.css` 附件放入 `.obsidian/themes/Tsukuyomi/`。

`SHA256SUMS.txt` 提供两个安装文件和 ZIP 的 SHA-256。升级替换同名文件，笔记内容不受影响。详细设置见 [README](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.0/README.md)。

## 验证与范围

自动测试覆盖构建、SVG 动画与回退约束、默认色板对比度和安装产物；真实应用证据来自 macOS Obsidian 1.13.7。其他平台、输入法组合输入、Style Settings 面板、打印及长期性能仍有未测项目。具体结果见 [验收记录](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.0/docs/VALIDATION.md)。
