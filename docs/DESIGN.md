# 设计说明

Tsukuyomi v0.3.0 以原作月读空间中的和风夜街为主要参考。界面通过冷暖色关系、前后层次和细檐线表达场景，阅读与编辑区域始终使用不透明的纯色背景。保留 Obsidian 与用户配置的字体、字号，正文默认宽度 `40rem`、行高 `1.75`。深浅模式跟随 Obsidian 的外观选择。

## 从场景到界面

以下将资料中的场景事实与本项目的设计取舍分开。来源及其用途见 [SOURCES.md](SOURCES.md)。

| 资料依据 | 本项目的转化 | 阅读边界 |
| --- | --- | --- |
| 制作访谈区分京都式街景、较低饱和度的游戏空间和激光演唱舞台 | 选择夜街作为日常工作环境的基调 | 持续阅读区域不承载演出效果 |
| 概念图中的深色斜屋顶、朱褐建筑、暖色灯笼与青绿天空 | 墨蓝侧栏、较亮的正文平面、海青交互色和少量月金 | 不给文件名铺底纹，不在字形上加光晕 |
| 制作资料展示屋檐、窗光、水镜及灯火的层次 | 通过细边线与不同明度划分工作区；空白页边缘保留简化远檐和灯笼 | 不把场景画进笔记标题或正文 |
| 屋形船等场景资产的灯笼 | 空白页右上角保留一盏简化纸灯笼 | 不闪烁，不遮挡空白页操作 |

这些是为笔记工具重新组织的视觉表达。色值不是官方标准色，也不是从电影画面精确取样的结果。

## 色彩与排版

深色「月读夜景」的正文背景为 `#1c2330`，侧栏为 `#131b28`，浮层为 `#252e3d`，正文为偏暖的 `#e9e3d5`，次级文字为 `#b6b4ba`。浅色「月白」保留纸白背景 `#f7f5f0`、侧栏 `#ecefea` 与深色正文 `#273442`。

| 色彩 | 深色 | 浅色 | 主要用途 |
| --- | --- | --- | --- |
| 海青 | `#82cabb` | `#0f706a` | 主强调、链接、焦点与选中状态 |
| 朱红 | `#e6a098` | `#ac3c50` | 错误、危险与未解析链接 |
| 月金 | `#dfc38a` | `#84621b` | 警告、代码强调与灯火 |
| 月紫 | `#bcb0df` | `#7053a2` | 外部链接、引用与辅助强调 |

标题通过字号、字重与间距建立层级，不使用发光、底纹和大型标题卡片。文件树采用纯色底，选中标记与键盘焦点仍保持可辨识。控件、内容块和浮层使用 `6 / 10 / 14px` 圆角，键盘 `:focus-visible` 使用 `2px` 轮廓。

原生主题色设置可覆盖链接、按钮和焦点的交互色，装饰与提示块保留主题配色。自动对比度检查针对默认色板；用户自定义颜色不在此保证范围。Canvas 保留红、橙、黄、绿、青蓝、紫六个颜色槽的区分。原生强调色文字适配的核对记录见 [native-color-reference.txt](native-color-reference.txt)。

`40rem` 是本项目的默认阅读宽度，可通过 Style Settings 调整，不等于任何字号下都恰好容纳 40 个汉字。W3C 的 CJK 行长和文字间距资料用于指导可读性取舍，不构成整个主题已通过 WCAG 的声明。

## 装饰与动效

空白标签页的场景完全由静态 CSS 绘制，包含右上角的小灯笼与底部远檐轮廓，不使用图片资源。装饰不接收指针事件。笔记、编辑器和文件列表没有场景图案；旧 `tk-home` 类仅保留兼容，不再触发专门的首页样式。

`tk-minimal` 关闭空白页场景与装饰性檐线；`tk-decoration-opacity` 控制整个空白页场景的透明度，默认 `0.10`。空白页窗格宽度不超过 `600px`、窗口宽度不超过 `600px` 或窗口高度不超过 `560px` 时，隐藏场景。主题自身动效默认关闭。启用 `tk-enable-motion` 后，仅在系统未请求减少动态效果时使用 `140ms` 的颜色、边框和阴影过渡，没有关键帧动画或全窗模糊。

## 兼容边界

主题优先覆盖 Obsidian 公共 CSS 变量，再为工作区和常用原生视图补充少量选择器。窄屏规则用于基础布局收敛，不据此宣称已完成移动端实机验证。打印规则移除装饰并恢复白底深色文字。

Style Settings 只是可选控制界面；没有该插件时，主题使用内置默认值正常工作。验证状态、桌面版本与未测项目统一记录在 [VALIDATION.md](VALIDATION.md)。
