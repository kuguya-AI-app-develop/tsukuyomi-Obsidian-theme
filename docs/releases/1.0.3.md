# Tsukuyomi 1.0.3

A focused print and link-style patch following the CSS diagnostics in the 1.0.2 review. The scene artwork, animations, and license scope are unchanged.

- Replace 11 print `!important` declarations with scoped selectors and native variables.
- Replace three link-decoration declarations with Obsidian's native link variables and a dashed editor border for unresolved links.
- Keep `break-after: avoid` and `break-inside: avoid` for printing. Each has a single-line compatibility-rule exception because doiuse groups these print-fragmentation declarations under multicolumn support. The rule remains enabled elsewhere; this is not a claim that all 16 diagnostics were rendering bugs.
- Add a [contributing guide](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.3/CONTRIBUTING.md) and document the [lint compatibility rationale](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.3/docs/LINT.md).

## Installation and status

Requires Obsidian **1.13.7 or later**. Download `Tsukuyomi-1.0.3.zip` and extract its `Tsukuyomi` folder into your vault's `.obsidian/themes/` directory, then select the theme in **Settings → Appearance**. The individual `manifest.json` and `theme.css` attachments are also supported.

Local validation: 23/23 tests, zero-error/zero-warning Stylelint, and a native six-page PDF comparison with identical text on corresponding pages. Official review of 1.0.3 is pending; client-directory synchronization remains unverified. Use manual installation while synchronization is pending. Actual checks and review status are recorded in [VALIDATION.md](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/VALIDATION.md) and [PUBLISHING.md](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/PUBLISHING.md); a web listing alone does not prove in-app availability.

MIT covers the maintainer's original software contributions; third-party character design rights remain excluded. See [NOTICE](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.3/NOTICE.md). Platform and interaction limits remain documented in the README; this patch does not claim broader platform coverage.
