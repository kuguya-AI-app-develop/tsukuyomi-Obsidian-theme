# 验收记录 · 0.6.0

日期：2026-09-16。按用户截图调整空白页鸟居与光镜的居中位置，给菜单独立布局空间，修复动效难以察觉的问题，并恢复 v0.2 的斜纹、细框和边缘几何纹理。

## 诊断与实现

- 旧版并非所有情况下都没有动画：真实应用获得焦点后可以观察到微小位移。隔离浏览器复现显示，不含 `is-focused` 类时，旧鱼层 `animation-play-state` 为 `paused`；获得该类时为 `running`。旧版单程仅移动 20px，耗时 24s，进一步降低了可见性。
- 本版移除空白页随窗口失焦暂停的条件。鱼层改为 8s 单程、水平 −32px 至 +32px；光镜透明度周期为 5s，菜单下方水波为 4s。仍限定活动空白页，保留静态开关和系统减少动态效果条件。
- 鸟居和光镜共用网格中间一格，上下可用空间对称时，图层中心就是窗格中心。菜单使用独立的下一行，水波在菜单之后正常排布；景物均不接收指针事件。受限空间优先保证菜单可用。
- 通过浏览器检查发现：窄窗格切回 flex 后，原 `align-self: start` 会使菜单偏左；已在响应式和打印回退中恢复居中。原生空白视图有确定的宽高，因此使用尺寸容器；窗格宽度不超过 600px 或高度不超过 560px 时隐藏五个场景图层，恢复原生居中菜单。
