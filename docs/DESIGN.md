# 设计说明

Tsukuyomi v0.2.0 采用更鲜明的和风虚拟舞台风格：以海军蓝、海青与朱红形成对比，通过云纹、网点、斜线和描边强化工作区与首页。装饰默认可见，笔记正文保留纯色背景。保留 Obsidian 与用户配置的字体和字号，正文默认宽度为 `44rem`、行高为 `1.75`。深浅模式跟随 Obsidian 的外观选择，不另建模式开关。

## 色彩

深色「月读夜景」的正文背景为 `#111b32`，侧栏为 `#0b1329`，正文为 `#e6edf3`；浅色「月白」的正文背景为 `#f7f5f0`，侧栏为 `#ecefea`，正文为 `#273442`。

四个语义强调色用于链接、状态、标题、代码和图形：

| 色彩 | 深色 | 浅色 | 主要用途 |
| --- | --- | --- | --- |
| 海青 | `#61d4c3` | `#0f706a` | 主强调、链接、焦点与选中状态 |
| 朱红 | `#f47d89` | `#ac3c50` | 错误、危险与未解析链接 |
| 月金 | `#e7c778` | `#84621b` | 警告与代码强调 |
| 月紫 | `#b6a2ea` | `#7053a2` | 外部链接、引用与辅助强调 |

基础组件圆角按 `6 / 10 / 14px` 分为控件、内容块和浮层三级；舞台首页使用不对称圆角与双层边框。文件选中项、当前标签和工作区边缘使用海青描边，朱红斜线作为少量辅助标记。键盘 `:focus-visible` 使用 `2px` 轮廓。

原生主题色设置可覆盖链接、按钮和焦点的交互色，装饰与提示块保留主题配色。自动对比度检查针对默认色板；用户自定义颜色不在此保证范围。Canvas 保留红、橙、黄、绿、青蓝、紫六个颜色槽的区分，辅以蓝色和橙色变量。原生强调色文字适配的核对记录见 [native-color-reference.txt](native-color-reference.txt)。

## 装饰与动效

工作区边框、月环、网点和斜线由 CSS 绘制，原创云纹保存在 `assets/stage-clouds.svg`，构建时内嵌到 CSS，不依赖图片服务器。首页以抽象月轮和海报式边框形成视觉中心，不使用人物插画。

默认在文件树、工作区边缘和空白标签页显示装饰。为笔记添加 `cssclasses: [tk-home]` 后，其阅读视图中的一级标题显示月轮、云纹与斜线组成的舞台卡片；普通笔记正文保留纯色背景。装饰不接收指针事件。`tk-minimal` 关闭舞台装饰，`tk-decoration-opacity` 调整侧栏网点与空白页月环的透明度，其他装饰通过简洁模式关闭。

主题自身动效默认关闭。启用 `tk-enable-motion` 后，仅在系统未请求减少动态效果时使用 `140ms` 的颜色、边框和阴影过渡。没有关键帧动画或全窗模糊。

## 兼容边界

主题优先覆盖 Obsidian 公共 CSS 变量，再为工作区和常用原生视图补充少量选择器。窄屏规则用于基础布局收敛，但当前不据此宣称已完成移动端实机验证。打印规则移除装饰并恢复白底深色文字。

Style Settings 只是可选控制界面；没有该插件时，主题使用内置默认值正常工作。验证状态、桌面版本与未测项目统一记录在 [VALIDATION.md](VALIDATION.md)。
