## 安装

需要 Obsidian **1.13.7 或更高版本**。下载 `Tsukuyomi-1.0.1.zip`，将其中的 `Tsukuyomi` 文件夹解压到笔记库的 `.obsidian/themes/`，然后在「设置 → 外观」选择 Tsukuyomi。也可将单独的 `manifest.json` 与 `theme.css` 附件放入 `.obsidian/themes/Tsukuyomi/`。

`SHA256SUMS.txt` 提供两个安装文件和 ZIP 的校验值。升级时替换同名文件即可，笔记内容不受影响。完整设置见 [README](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.1/README.md)。
