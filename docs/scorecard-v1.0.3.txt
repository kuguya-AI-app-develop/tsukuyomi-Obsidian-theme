  - text: "Tsukuyomi brings midnight blue, sea-green lights, and Japanese-inspired scenery to the workspace while keeping notes on solid, quiet reading surfaces. It includes dark and light modes, a decorated sidebar, and an empty view with swimming fish and four small companions. Optional Style Settings controls include reading width, density, a minimal mode, scene opacity, and a static scene. Reduced-motion preferences are respected. Assets are embedded: no network requests, runtime JavaScript, or required plugins. Tested on macOS with Obsidian 1.13.7; other platforms remain unverified. This is a free, noncommercial fan project, unaffiliated with Obsidian or the original creators. Original software code is MIT-licensed; underlying third-party character rights are excluded.
