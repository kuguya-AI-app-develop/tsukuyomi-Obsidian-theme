# Tsukuyomi 1.0.2

Documentation update following the first Obsidian Community review: the main README is now fully in English, with a separate Chinese version. The theme's appearance, animations, artwork and license scope are unchanged.

Requires Obsidian 1.13.7 or later. Download `Tsukuyomi-1.0.2.zip` and extract its `Tsukuyomi` folder into your vault's `.obsidian/themes/` directory, then select the theme in Settings → Appearance. The individual `manifest.json` and `theme.css` attachments are also available, with SHA-256 checksums.

This is an unofficial, free, noncommercial fan project. MIT covers the maintainer's original software contributions; third-party character design rights remain excluded. See [NOTICE](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.2/NOTICE.md).

The official 1.0.2 review is complete with no blocking errors. Its English README warning is resolved; 16 non-blocking CSS warnings remain. Tsukuyomi is now available in the [Obsidian Community directory](https://community.obsidian.md/themes/tsukuyomi), with Health: Excellent and Review: Satisfactory. Use Add to Obsidian on that page, or search for Tsukuyomi in Settings → Appearance → Themes → Manage. See the [publishing record](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/main/docs/PUBLISHING.md) for evidence.
