# Tsukuyomi 1.0.4

A compact-layout fix following an iPhone 14 Pro report: the empty scene and sidebar sign were hidden, while an empty file toolbar retained a flattened decorative frame.

- Keep a compact stage and action menu on narrow screens, with space reserved for native top and bottom controls.
- Restore an 80px sidebar sign and remove the frame from an empty file toolbar while preserving its native bottom controls.
- Allow animation when both the viewport and empty pane are at least `320 × 480`, while retaining active-pane, reduced-motion, Static scene, and Minimal mode safeguards. Artwork adapts to available space; note content stays still.

## Validation scope

Local checks passed: **24/24 tests**, including source guard regressions, and **0 Stylelint errors / 0 warnings**. The existing two local print-fragmentation exceptions remain. The CSS is **81,856 bytes**, and installation into the project lab vault completed.

Desktop-browser checks used the locally installed **Obsidian 1.13.7 CSS with simulated DOM**:

- All scene layers and both animated SVGs were selected at `393 × 852`, `375 × 667`, `320 × 568`, and `430 × 932`. The three 48px menu controls passed center-point hit checks, with no horizontal overflow. Rendered frame comparisons showed changes in companion and fish pixels.
- At `852 × 393`, the scene was hidden because the height was below 480px; the menu remained clickable. A 280px split pane also hid the scene. The `1024 × 768` desktop menu coordinates matched 1.0.3.
- Dark/light modes, Static scene, Minimal mode, inactive panes, and decoration isolation from a 393px reading view passed. In the 393px viewport sidebar check, the compact sign measured 80px and all four 44px native toolbar controls passed center-point hit checks.

These are **not native iOS results or touch-gesture tests**. User verification on the iPhone remains necessary. Actual OS reduced-motion switching was not tested; its guards were checked automatically. Mobile editing, keyboard behavior, battery use, touch gestures, iPad, and Android remain untested.

The two non-blocking print-fragmentation warnings in the official **1.0.3** review remain part of that historical record. Official review status for **1.0.4** is pending confirmation, and client-directory synchronization has not been reverified. ## Manual installation

Requires Obsidian **1.13.7 or later**. Download `Tsukuyomi-1.0.4.zip` and extract the `Tsukuyomi` folder into your vault's `.obsidian/themes/` directory, then select the theme in **Settings → Appearance**. You may also install the individual `manifest.json` and `theme.css` attachments.

The existing [license and artwork scope](https://github.com/kuguya-AI-app-develop/tsukuyomi-Obsidian-theme/blob/1.0.4/NOTICE.md) is unchanged.
