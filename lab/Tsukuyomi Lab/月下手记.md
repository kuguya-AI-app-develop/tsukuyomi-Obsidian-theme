# 把灵感留在月光里

TSUKUYOMI · 一页安静的创作空间

夜深的时候，让文字慢慢落在纸上。记下一段偶然听见的旋律、一场还未结束的对话，或者一个暂时没有名字的想法。侧栏的灯光留在远处，阅读区只留下清楚的文字与舒适的留白。

> [!tsukuyomi] 月下记录
> 不必急着写完。把此刻最想记住的一句话，留给明天的自己。

## 今夜的航线

| 一件小事 | 留下的线索 |
| :--- | :--- |
| 阅读几个段落 | 标记一句值得再读的话 |
| 整理新的想法 | 用 [链接](00-欢迎来到月读.md) 连起零散的笔记 |
| 写下一页手记 | 给未完成的故事留一点空间 |

### 写作清单

- [x] 为今天的灵感起一个名字
- [ ] 写下故事的下一段
- [ ] 明天，再读一遍

细节可以慢慢补充，想法也可以重新排列。**专注眼前的一段文字**，让余下的时间属于阅读。
